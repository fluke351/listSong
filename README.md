# 🎵 คิวเพลง YouTube สำหรับวง LAN (ไม่มีโฆษณา)

ทุกคนในวง LAN เดียวกันเปิดเว็บ แล้ว**ค้นหาเพลง**หรือ**วางลิงก์ YouTube** เพื่อต่อคิวได้ทันที
เพลงจะเล่นออกลำโพงที่เครื่องเซิร์ฟเวอร์

**ทำไมไม่มีโฆษณา:** โปรแกรมไม่ได้ใช้ตัวเล่นของ YouTube
เซิร์ฟเวอร์ใช้ `yt-dlp` ดาวน์โหลดเฉพาะไฟล์เสียงมาเก็บไว้ในเครื่อง แล้วเล่นด้วยตัวเล่นเสียงของเบราว์เซอร์เอง
จึงไม่มีโฆษณาคั่นหรือขึ้นก่อนเพลง

## ติดตั้งบนเครื่องใหม่ (กดทีเดียว)

**[⬇ ดาวน์โหลด listSong.exe](https://github.com/fluke351/listSong/releases/latest/download/listSong.exe)** (ไฟล์เดียว ขนาดประมาณ 300 KB) แล้วดับเบิลคลิก หรือก๊อปไฟล์นี้ไปเครื่องอื่นก็ได้

- ถ้า Windows ขึ้นหน้าต่าง "Windows protected your PC" ให้กด **More info** แล้วกด **Run anyway** (ขึ้นเพราะไฟล์ไม่ได้ลงลายเซ็นดิจิทัล)
- โปรแกรมจะติดตั้งไว้ที่ `%LOCALAPPDATA%\listSong` หลังติดตั้งแล้วลบไฟล์ exe ที่ดาวน์โหลดมาทิ้งได้
- ถ้าได้ exe เวอร์ชันใหม่ ให้ดับเบิลคลิกได้เลย จะอัปเดตทับให้เอง คิวและเพลงที่เก็บไว้ยังอยู่
  ถ้าโปรแกรมเวอร์ชันเก่ายังเปิดอยู่ ตัวใหม่จะปิดตัวเก่า (รวมหน้าต่างของมัน) แล้วเปิดตัวเองแทนให้อัตโนมัติ

ครั้งแรกโปรแกรมจะทำทุกอย่างให้เอง:
- ดาวน์โหลด Node.js และ yt-dlp มาไว้ในโฟลเดอร์ `bin\` (ไม่ต้องติดตั้งอะไรเพิ่ม และไม่ต้องใช้สิทธิ์ admin)
- ขออนุญาตเปิดไฟร์วอลล์ให้เครื่องอื่นในวง LAN เข้ามาได้ → กด **Yes** ครั้งเดียว
- สร้างทางลัด **"คิวเพลง"** บนหน้าจอ ครั้งต่อไปดับเบิลคลิกที่ทางลัดนี้ได้เลย
- เปิดโปรแกรมและเปิดหน้าเครื่องลำโพงในเบราว์เซอร์ให้อัตโนมัติ

ต้องต่ออินเทอร์เน็ตตอนเปิดครั้งแรก (ไฟล์ที่ต้องโหลดรวมประมาณ 110 MB) ระบบจะอัปเดต yt-dlp ให้เองทุก 7 วัน

หรือจะใช้แบบ zip ก็ได้: แตกไฟล์ `listSong.zip` แล้วดับเบิลคลิก `start.bat` (ทำงานเหมือนกัน แต่ใช้โฟลเดอร์ที่แตกไฟล์ไว้แทน)

**สร้าง exe/zip ใหม่หลังแก้โปรแกรม:** ดับเบิลคลิก `pack.bat` จะได้ไฟล์ `dist\listSong.exe` และ `dist\listSong.zip`
(ใช้ตัวคอมไพล์ C# ที่มากับ Windows ไม่ต้องติดตั้งอะไรเพิ่ม)

## วิธีใช้

1. เปิดโปรแกรม (ดับเบิลคลิก `start.bat` หรือทางลัด "คิวเพลง")
2. หน้าเครื่องลำโพงจะเปิดขึ้นมา ให้กดปุ่ม **▶ เริ่มเป็นเครื่องลำโพง** 1 ครั้ง (เบราว์เซอร์บังคับให้กดก่อนจึงเล่นเสียงได้)
3. ส่งที่อยู่ที่แสดงในหน้าเว็บ (เช่น `http://192.168.1.25:3100`) ให้เพื่อน กดปุ่ม **คัดลอก** ได้
4. เพื่อนเปิดลิงก์นั้นบนมือถือหรือคอมพิวเตอร์ แล้วเพิ่มเพลงได้ 2 วิธี:
   - **ค้นหา:** พิมพ์ชื่อเพลงแล้วกด Enter จากนั้นกด ＋ ที่เพลงที่ต้องการ
   - **วางลิงก์:** วางลิงก์ YouTube เพลงจะเข้าคิวทันที วางหลายลิงก์พร้อมกันได้

ลิงก์ที่ใช้ได้: `youtube.com/watch?v=…`, `youtu.be/…`, `youtube.com/shorts/…`, `music.youtube.com/watch?v=…`
(ลิงก์ที่มี `&list=` จะเพิ่มแค่เพลงนั้นเพลงเดียว ไม่ได้เพิ่มทั้งเพลย์ลิสต์)

**เพิ่มเพลงซ้ำไม่ได้:** ถ้าเพลงนั้นกำลังเล่นหรืออยู่ในคิวแล้ว ระบบจะแจ้งว่าอยู่ลำดับที่เท่าไร ในผลการค้นหาจะขึ้นป้าย "อยู่ในคิวแล้ว"
เมื่อเพลงเล่นจบไปแล้ว จึงเพิ่มเพลงนั้นได้อีกครั้ง

**คนที่เปิดลิงก์ LAN ทำได้:** ค้นหา, วางลิงก์, เพิ่มเพลงที่เล่นไปแล้วกลับเข้าคิว และเลื่อนลำดับคิว
ส่วนการหยุดหรือเล่นต่อ, ข้ามเพลง, ปรับเสียงลำโพง, ลบเพลง และล้างคิว ทำได้เฉพาะที่เครื่องลำโพง (เครื่องที่เปิดโปรแกรม)

**อ่านชื่อเพลงก่อนเล่น:** ก่อนเริ่มแต่ละเพลง เครื่องลำโพงจะพูดว่า "ต่อไปเพลง … ขอโดย …" (ตัดวงเล็บอย่าง (Official MV) ออกให้)
เปิด/ปิดได้ที่ปุ่ม 💬 ข้างปุ่มข้ามเพลงในหน้าเครื่องลำโพง เสียงอ่านมาจาก Google Translate (ต้องต่ออินเทอร์เน็ต ระบบส่งข้อความที่จะอ่าน คือชื่อเพลงและชื่อคนขอ ไปที่ Google) ถ้าต่อไม่ได้จะใช้เสียงภาษาไทยของเบราว์เซอร์แทน ซึ่งฟังไม่ชัดเท่า

**ฟังด้วยบนเครื่องตัวเอง:** กดปุ่ม 🎧 **ฟังด้วย** ใต้เพลงที่กำลังเล่น เครื่องนั้นจะเล่นเพลงเดียวกับเครื่องลำโพง ตรงตำแหน่งเดียวกัน (คลาดกันไม่เกินประมาณ 1 วินาที)
หยุดหรือเล่นต่อตามเครื่องลำโพง ปรับเสียงของเครื่องตัวเองได้ และไม่กระทบเครื่องลำโพง ถ้าปิดหน้าเครื่องลำโพงไว้ เสียงที่ฟังด้วยจะหยุดรอ

**ต้องกรอกชื่อก่อนขอเพลง:** กรอกชื่อในช่อง "ชื่อคุณ" ใต้ช่องค้นหา เบราว์เซอร์จะจำไว้ให้ครั้งต่อไป ถ้ายังไม่กรอก จะเพิ่มเพลงไม่ได้ (ค้นหาได้ตามปกติ)

**ล้างอัตโนมัติทุกวันเวลา 17:30:** ล้างรายการ "เล่นไปแล้ว" และลบไฟล์เพลงที่เก็บไว้ (เพลงที่กำลังเล่นหรือรออยู่ในคิวไม่ถูกลบ) ถ้าตอน 17:30 โปรแกรมปิดอยู่ จะล้างให้ตอนเปิดครั้งถัดไป

## ถ้าเครื่องอื่นเข้าไม่ได้

- ตอนที่ `start.bat` ขออนุญาตเปิดไฟร์วอลล์ ต้องกด **Yes** ถ้าเผลอกด No ให้ลบทางลัดแล้วเปิด `start.bat` ใหม่ หรือเปิด PowerShell แบบ **Run as administrator** แล้วรันคำสั่งนี้:

  ```powershell
  netsh advfirewall firewall add rule name="listSong (TCP 3100)" dir=in action=allow protocol=TCP localport=3100 profile=domain,private
  ```

- ทุกเครื่องต้องต่อ Wi-Fi หรือ LAN วงเดียวกัน
- ไฟร์วอลล์เปิดให้เฉพาะเครือข่ายบริษัท (Domain) และเครือข่ายส่วนตัว (Private) ถ้า Windows ตั้ง Wi-Fi ที่บ้านเป็น **Public** เครื่องอื่นจะเข้าไม่ได้
  ให้ไปที่ Settings → Network & internet → Wi-Fi → เลือกวงนั้น → ตั้ง Network profile เป็น **Private**
- ต้องเปิดผ่านชื่อเครื่องหรือ IP ของเครื่องลำโพงเท่านั้น (ชื่อโดเมนอื่นที่ชี้มาจะถูกปฏิเสธ เพื่อกันเว็บอื่นแอบสั่งคิวเพลง)
- Wi-Fi ของบริษัทหรือ Wi-Fi สาธารณะบางที่ บล็อกการเชื่อมต่อระหว่างเครื่องไว้ ถ้าเป็นแบบนั้นให้ใช้ Wi-Fi หรือ hotspot ของตัวเองแทน

## การตั้งค่า (environment variables)

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `PORT` | `3100` | พอร์ตของเว็บ |
| `CACHE_MAX_MB` | `500` | พื้นที่สูงสุดสำหรับเก็บเพลงที่เล่นไปแล้ว ถ้าเกินจะลบเพลงที่ไม่ได้เปิดนานที่สุดก่อน (ตั้งเป็น `0` = ลบทันทีหลังเล่นจบ) |
| `HISTORY_RESET` | `17:30` | เวลาที่ล้างรายการ "เล่นไปแล้ว" และไฟล์เพลงที่เก็บไว้ทุกวัน (ชั่วโมง:นาที) |
| `YTDLP_PATH` | `bin\yt-dlp.exe` หรือ `yt-dlp` ใน PATH | ตำแหน่งของ yt-dlp |

ตัวอย่าง: ใส่บรรทัด `set CACHE_MAX_MB=200` ใน `start.bat` ก่อนบรรทัด `"%NODE%" server.js`

## หมายเหตุ

- ไฟล์เสียงเก็บไว้ในโฟลเดอร์ `cache\` และ**ลบอัตโนมัติ เครื่องไม่เต็ม**:
  - เพลงที่กำลังเล่นหรืออยู่ในคิวจะเก็บไว้เสมอ
  - เพลงที่เล่นไปแล้วเก็บไว้ไม่เกิน 500 MB (ประมาณ 150 เพลง) เพื่อให้เปิดซ้ำได้ทันที ถ้าเกินจะลบเพลงที่ไม่ได้เปิดนานที่สุดก่อน
  - ไฟล์ที่ค้างจากการโหลดไม่สำเร็จก็ลบให้เอง
- คิวถูกบันทึกไว้ที่ `data\state.json` ปิดแล้วเปิดโปรแกรมใหม่คิวยังอยู่
- ระบบโหลดเพลงล่วงหน้า 3 เพลงถัดไป เพื่อให้เล่นต่อกันได้โดยไม่ต้องรอ
- ควรเปิดหน้า `/player` ไว้แค่เครื่องเดียว ถ้าเปิดหลายแท็บ เสียงจะเล่นซ้อนกัน
- ถ้าดับเบิลคลิก `start.bat` ตอนที่โปรแกรมเปิดอยู่แล้ว ระบบจะไม่เปิดโปรแกรมซ้ำ แค่เปิดหน้าเว็บให้
